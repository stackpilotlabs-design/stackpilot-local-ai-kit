# Local AI Starter Kit for Mac

> Product overview and status: [README.md](README.md)

## Product Goal

Help developers, students, and professionals run modern AI models locally on Apple Silicon Macs without requiring expensive hardware, cloud subscriptions, or advanced machine learning knowledge.

---

## Who This Is For

* Developers exploring local AI
* Students learning modern AI tools
* Technical professionals seeking privacy-first AI workflows
* AI enthusiasts running models on personal hardware

---

## What You Will Learn

By the end of this guide you will be able to:

* Understand the strengths and limitations of local AI
* Install and use LM Studio
* Install and use Ollama
* Select appropriate models for your hardware
* Benchmark local models consistently
* Troubleshoot common issues
* Build practical local AI workflows
